# Contributing

Thanks for your interest in contributing. Before opening a pull request:

1. Open an issue describing the problem or proposed change.
2. Keep changes focused and include tests where practical.
3. Do not include credentials, customer data, production URLs containing private paths, or personal information.
4. Never commit `.env`, backups, database dumps, access tokens, private keys, or live configuration.
5. Explain any database migration and its rollback implications.

By submitting a contribution, you agree that it may be distributed under the repository's GPL-2.0-or-later license.
