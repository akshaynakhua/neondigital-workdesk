# Public source release notes

This is a curated source snapshot, not a production-ready or independently certified release.

Excluded from the public archive: internal release notes, historical test fixtures, integration configuration guides, database schema reference, brand asset bundle, and draft legal documents. The source still contains application-specific integration endpoints and references to NeonDigital domains.

Before making a repository public, the maintainer must review: ownership and third-party licenses, PHP/WordPress compatibility, authentication/authorization, data handling, and whether proprietary features are intended for public distribution.

**Important:** If sensitive values were ever committed to a Git repository, removing them from current files does not remove them from Git history. Rotate exposed credentials and rewrite history as appropriate.
